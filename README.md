# Pausepoint – Datenschutzerklärung

Diese Seite hostet die Datenschutzerklärung für die Android-App **Pausepoint**
(`com.derdenker.pausepoint`) für den Google-Play-Eintrag.

**Öffentliche URL:** https://renuanderdenker.github.io/pausepoint-privacy/

Der Text steht in [`index.html`](index.html). Vor der Veröffentlichung im Play
Store im Block „Anbieter / verantwortlich für die Datenverarbeitung“ den
Platzhalter `[Dein Name bzw. Entwicklername]` durch den echten Namen ersetzen
(muss mit dem Entwicklernamen im Play-Konto übereinstimmen).
